## Verification matrix

- **Surface:** real dashboard and all widget families; search/screener; company and bank views; VniAgent/source links; settings/auth/shared research; loading/empty/stale/partial/failure/offline; export downloads.
- **Presentation:** 1440/1024/390 px, light/dark, color-vision and reduced-motion modes, keyboard/focus/touch, Vietnamese fonts/fallbacks. Text ≥4.5:1; large text and essential non-text ≥3:1. Recheck Auto-fit, mobile identity, logo clear space and one authoritative title.
- **Behavior/data:** FPT and VCB; units/periods/estimates; missing/non-meaningful/zero; timestamps; export metadata; deep links; workspace/tab switching; grid resize; saved layout/theme reload and backup/restore. Keep a small regression check for changed state/export invariants, not wording/token snapshots.
- **Financial golden cases:** one small runnable check for the changed signed-change formatter covers positive, negative, true zero (`0.0%`, not `+0.0%`) and missing (`n/a`). Verify 3.2% to 3.5% is `+0.3 pp`, forecasts are labeled (for example `FY2027F`), and calculations use full-precision inputs before display rounding. Neutral ordinary magnitudes and missing-versus-zero remain separate from direction coloring.
- **Commands, not run for this plan:** `pnpm run ci:gate`; `pnpm --filter frontend test:e2e:smoke`. Browser interaction remains required; passing tests alone is not visual proof.

No ingestion, source-permission, database recovery, route/tool/schema renaming or new help/legal/landing system is included. Preserve truthful data-health warnings. Small-icon approval blocks that artwork, not the rest of the overhaul.
